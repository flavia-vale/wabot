# Espelha Grupos — documentação pública

O **Espelha Grupos** é um software web brasileiro para afiliadas e admins de
grupos de WhatsApp. Ele espelha ofertas de grupos e canais de origem para os
seus grupos de destino, troca cada link pelo seu código de afiliada (Shopee,
Mercado Livre, Amazon, Magalu, SHEIN, AliExpress) e publica com filas,
intervalos e histórico de envios.

Site: https://espelhagrupos.com.br · Planos e preços atuais: https://espelhagrupos.com.br/precos

## O que há aqui

- [`GLOSSARIO.md`](GLOSSARIO.md): termos de quem divulga ofertas (espelhamento, link monetizado, cadência…).
- [`EXEMPLO_MENSAGEM.md`](EXEMPLO_MENSAGEM.md): exemplo de mensagem antes e depois da conversão do link.
- Metodologia de uso responsável: https://espelhagrupos.com.br/metodologia-uso-responsavel-whatsapp

## O que este repositório não é

- Não é o código do produto (o código não é aberto).
- Não promete resultado de vendas nem que uma conta nunca será restringida: quem decide restrições é o WhatsApp.
- "Espelhamento", aqui, não tem relação com espelhar a tela do celular nem com o WhatsApp Web em dois aparelhos.
