# Exemplo de mensagem convertida

Exemplo ilustrativo, com produto e links fictícios.

**Mensagem no grupo de origem**

```
🔥 Fone Bluetooth XYZ
De R$ 199 por R$ 129
https://loja.exemplo/produto/123?ref=OUTRA-PESSOA
```

**Mensagem publicada no seu grupo de destino**

```
🔥 Fone Bluetooth XYZ
De R$ 199 por R$ 129
https://loja.exemplo/produto/123?ref=SEU-CODIGO
```

O texto e a oferta são os mesmos. O que muda é o link: ele passa a levar o
**seu** código de afiliada, para a comissão da venda ser atribuída a você.
Se um link não puder ser convertido, a oferta não deve ser publicada com o
link de outra pessoa.

Como cada loja identifica a afiliada (tag, código, parâmetro) varia por loja e
por regra do programa: confira sempre no programa de afiliados da loja.
