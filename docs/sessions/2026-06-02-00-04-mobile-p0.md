# Sessão: implementação P0 mobile

## Mudanças

- Implementadas rotas mobile para ofertas automáticas, broadcast manual segmentado e ganchos/CTAs persistidos no backend.
- Expandido cadastro mobile de canais em Grupos e Canais com link de convite, canais seguidos e JID resolvido.
- Atualizados atalhos da Conta e guia rápido mobile para as rotas operacionais.
- Atualizado estudo de paridade para registrar P0 como implementado.

## Decisões

- Nenhum contrato backend, schema, migration ou env foi alterado.
- Agendamentos continuam com o contrato existente (`text`, `scheduledAt`) e não receberam seleção explícita de destinos.
- Ganchos/CTAs backend foram mantidos separados dos modelos locais de oferta.
