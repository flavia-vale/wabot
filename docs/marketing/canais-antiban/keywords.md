5. Blog posts para nutrir e sustentar SEO.

## Regras editoriais

- Não criar páginas quase iguais trocando apenas palavra-chave.
- Cada página precisa responder a uma intenção específica.
- Usar links internos para formar hub-and-spoke.
- FAQ deve responder objeções reais, não repetir headline.
- Usar “Módulo de Preservação Avançada” como termo principal nas próximas sprints.
- Manter “anti-ban” apenas entre aspas para SEO e descrições de intenção.
- Evitar keyword stuffing.
