# Sales enablement — BOTinho

Materiais de venda 1:1 (DM, WhatsApp, conversa com admin de grupo/canal),
complementares ao site público. Diferente das páginas de SEO em
`dashboard/app/`, estes arquivos são para uso interno de quem está vendendo
— não são publicados como rota.

Nasceram do plano de lançamento da v1 (jul/2026): o produto já tinha uma
base de marketing madura (ver `docs/marketing/*`), mas nada pensado para
conversa direta com um lead específico.

## Arquivos

| Arquivo | Uso |
|---|---|
| `one-pager.md` | Enviar por WhatsApp/DM após primeiro contato. Problema → solução → diferenciais → CTA. |
| `quadro-objecoes.md` | Consulta rápida durante a conversa — resposta pronta para as objeções mais comuns. |
| `kit-programa-indicacao.md` | Texto e passo a passo para transformar cliente satisfeito em divulgador (o programa de indicação já existe em `painel/afiliados`, só faltava material). |
| `case-studies-template.md` | Estrutura para registrar casos reais à medida que forem coletados. **Vazio de propósito** — não preencher com dado fabricado. |

## Regra que não muda

Nenhum número, depoimento ou resultado de cliente entra nestes arquivos sem
ser real e verificável. Preferir "ainda não temos esse dado" a inventar um
número — é a mesma disciplina já aplicada em `pricing.md`, `llms.txt` e no
FAQ público.
